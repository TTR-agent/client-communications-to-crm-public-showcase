# Sanitization Notes

Preserved:

- Communication-to-action workflow shape.
- Team handoff logic.
- CRM status recommendation pattern.
- Feedback-loop capture.
- Human review boundary before CRM writes.

Changed or removed:

- Real client names, companies, contacts, domains, and transcripts.
- Real CRM object IDs, field IDs, list IDs, and workspace URLs.
- Credentials, webhook URLs, tokens, and API request logs.
- Private prompts and internal operating language.
- Any client-specific commercial context.

The examples are synthetic but intentionally realistic enough to show how the system maps messy communication into structured operational follow-through.
